# 🌟 Mentor AI Aura

**Mentor AI Aura** is an all-in-one AI-powered career accelerator and mentorship platform. It provides end-to-end guidance for software developers and tech candidates through intelligent resume auditing and personalized AI mentorship.

### Resume-based job recommendations

After a resume is analyzed, the app ranks available job listings using matched skills, the resume ATS score, and any experience or education requirements that can be verified from the parsed resume. The fit percentage is an explainable profile-to-listing estimate, not a probability of being hired. Job sources are checked every five minutes while the app is open; users should verify vacancy status and eligibility on the official listing before applying.
